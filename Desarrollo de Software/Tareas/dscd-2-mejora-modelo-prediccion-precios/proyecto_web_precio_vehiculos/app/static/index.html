Caso de uso: valuacion de vehiculos usados

Valuador de Autos

La web captura los datos de un vehiculo, llama una API FastAPI y esa API consulta la inferencia de un modelo de Extra Trees para estimar el precio de venta.

Idea de uso

Un asesor de ventas captura los datos tecnicos del vehiculo (nombre, combustible, transmision, kilometraje, motor, potencia, etc.). La app devuelve un precio estimado y guarda cada consulta en SQLite para dar seguimiento.

Flujo tecnico

Frontend HTML/JS → POST /predict-price → API FastAPI → pipeline (preprocessing + Extra Trees Regressor) serializado con joblib → respuesta JSON → historial en GET /api/price-predictions.

Consultar el modelo

Ingresa los datos del vehiculo para obtener un precio estimado al instante.

Como consumir la API

La UI manda JSON a la API. El backend responde con el precio estimado y la version del modelo. 

POST /predict-price
{
  "name": "Maruti Swift Dzire VDI",
  "fuel": "Diesel",
  "seats": "5",
  "seller_type": "Individual",
  "transmission": "Manual",
  "owner": "First Owner",
  "year": 2021,
  "km_driven": 45000,
  "mileage": 23.4,
  "engine": 1248,
  "max_power": 74,
  "torque": 190
}

Respuesta: estimated_price, currency y model_version.
